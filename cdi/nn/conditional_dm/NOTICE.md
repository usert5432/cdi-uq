# Conditional Diffusion Transformer Attribution

The conditional diffusion transformer architecture in this package is adapted
from the JCDI power-grid implementation:

- Repository: https://github.com/fq123fq/JCDI-power-grid
- Paper: "Joint Conditional Diffusion Models for Power Grid Sensor Data
  Generation"
- Authors: Feiqin Zhu, Dmitrii Torbunov, Yihui Ren, Zhongjing Jiang,
  Tianqiao Zhao, Amirthagunaraj Yogarathnam, and Meng Yue

The implementation in CDI has been modified for CBED/CDI regression and uses
PyTorch's built-in transformer encoder modules.
